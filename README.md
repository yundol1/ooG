# ooG (우그)

취미로 이어지는 사람과 모임 — 취미 소모임 프라이빗 피드 & 1:1 매칭 웹앱.

- 처음 열면 **회원가입**으로 시작합니다 — 닉네임·프로필 사진(앨범/카메라)·나이·지역·취미를 정해 내 계정을 만드세요. 아무 정보 없이 '간편 시작'도 됩니다.
- 가입 직후에도 **바로 눌러 볼 수 있는 최소 예시 데이터**가 들어 있습니다(예시 모임 2곳·둘러볼 모임 3곳·사람 4명·동네 글 4개·1:1 대화 2개). 모두 가상의 가명이며 설정 › 데이터 관리에서 **예시 데이터 비우기 / 다시 넣기**로 관리할 수 있습니다.
- 예시 모임의 대표 이미지와 추천 피드 사진으로 **사진 8장**이 들어 있습니다(위치·기기 정보를 지우고 4:3·960px 로 다시 저장). 내가 올리는 사진은 앨범/카메라로 고른 것만 씁니다.
- 홈 화면에 추가하면 앱처럼 실행됩니다(PWA · 오프라인 캐시).
- 빌드가 없는 정적 사이트라 Vercel · GitHub Pages 어디에나 그대로 올릴 수 있습니다(`vercel.json` 포함).

이 저장소는 빌드 없이 바로 실행되는 정적 파일만 담고 있습니다 — `index.html`, `css/`, `js/`, `icons/`, `assets/`, `manifest.json`, `sw.js`.
접속하면 배경 그림 위에 `ooG` 로고가 잠깐 떠오릅니다.
(테스트·미리보기용 `#demo` 화면의 사람·모임은 모두 가상의 예시이며, 실제 방문자도 가상의 예시 데이터로 시작합니다.)
