# ooG (우그)

취미로 이어지는 사람과 모임 — 취미 소모임 프라이빗 피드 & 1:1 매칭 웹앱.

- 처음 열면 **회원가입**으로 시작합니다 — 닉네임·프로필 사진(앨범/카메라)·나이·지역·취미를 정해 내 계정을 만드세요. 아무 정보 없이 '간편 시작'도 됩니다.
- 가입 직후에는 **정말 비어 있는 앱**입니다(모임·피드·게시판·사람 0). 첫 모임을 만들면 그때부터 내 피드와 게시판이 채워집니다.
- 예시 이미지·기본 일러스트는 쓰지 않습니다. 사진은 앨범/카메라로 올린 것만 보입니다.
- 홈 화면에 추가하면 앱처럼 실행됩니다(PWA · 오프라인 캐시).
- 빌드가 없는 정적 사이트라 Vercel · GitHub Pages 어디에나 그대로 올릴 수 있습니다(`vercel.json` 포함).

이 저장소는 빌드 없이 바로 실행되는 정적 파일만 담고 있습니다 — `index.html`, `css/`, `js/`, `icons/`, `manifest.json`, `sw.js`.
(테스트·미리보기용 `#demo` 화면의 사람·모임은 모두 가상의 예시이며, 실제 방문자는 빈 앱에서 시작합니다.)
